# NovasPay 管理端 QA 流程

插件按这个顺序跑。标成「自动」的步骤自己点页面；标成「人工」的步骤会停住，侧边栏出现说明，做完点「已完成，继续」。判定失败就点「不通过」。

1. 鉴权：退出 → 错误密码 → 正确登录 → 人工确认刷新后仍在登录态
2. 导航：自动打开全部业务页
3. 支付：自动核对原始密钥、点探活、打开测试下单 → 人工完成 Sandbox 支付并确认回调
4. 商品：自动搜索 → 人工确认可下单商品
5. 账务：自动打开交易、退款、对账、结算、报表 → 人工核对入账、退款边界、以及这些页不能当成真实打款验收
6. 邮件：自动打开测试发信 → 人工确认收件箱
7. 权限：自动打开角色和用户页 → 人工用非超管账号核对菜单
8. 收尾：退出后改地址也不能进看板
